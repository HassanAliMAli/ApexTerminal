# Local development

Use the [native development setup](../docs/tutorials/contribute/run-the-development-stack.md) and [startup guide](../docs/tutorials/build-from-source/run-the-stack-from-source.md).

## Widget plugins

Set `WIDGET_PLUGINS_DIR` to the repository’s `widget-plugins` directory or another absolute package path. Give the API read access and restart it after changing the setting.
