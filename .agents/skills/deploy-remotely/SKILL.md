# Deploy to a Linux server

Use `docs/tutorials/deploy/production-setup.mdx` and the native source setup. Confirm the authorized target before changing it. Keep the database and cache private, supervise services independently, use production mode, and set the actual HTTPS origins. Verify migrations, health and sign-in.
